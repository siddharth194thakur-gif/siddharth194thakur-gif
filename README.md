## 📌 Featured Projects

### 🏢 [HostelTalkies — Campus & Hostel Community Platform](https://hosteltalkies.fun)
*A full-stack campus and hostel web platform connecting students, peer trading, academic notes, and administration.*

- **Backend Repository**: [Hostel-Talkies-Backend](https://github.com/siddharth194thakur-gif/Hostel-Talkies-Backend)
- **Frontend Repository**: [Hostel-Talkies-Frontend](https://github.com/siddharth194thakur-gif/Hostel-Talkies-Frontend)
- **Live Demo**: [hosteltalkies.fun](https://hosteltalkies.fun)
- **Technologies**: Python, Django 5, Django REST Framework, PostgreSQL, SimpleJWT, React 19, TypeScript, Tailwind CSS, Vite.
- **Key Features**:
  - **Hostel Hierarchy**: Dynamic cascading selection of hostels, blocks, and rooms with live status tracking.
  - **Peer-to-Peer Marketplace & Borrow Tracker**: Student listings, item giveaways, and borrow/lend request workflows.
  - **Academic Study Repository**: Downloadable university lecture notes, semester study resources, and previous year questions (PYQs).
  - **Campus Notices & Events**: Official administration announcements and upcoming event activity boards with hostel/block targeting.
  - **Security & Reliability**: JWT authentication with refresh token lifecycle, defensive CORS configuration, rate limiting, and database connectivity resilience.
